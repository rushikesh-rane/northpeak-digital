# NorthPeak Digital

NorthPeak Digital is a responsive landing page for a fictional digital agency. This project was built using HTML, CSS, and Vanilla JavaScript as part of the Digital Heroes Internship Qualification Task.

## Features

- Responsive design for desktop, tablet, and mobile
- Modern hero section
- Services section
- Testimonials
- Pricing plans
- Contact form with client-side validation
- Local Storage support for contact form submissions
- Clean and organized project structure

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Lucide Icons
- Google Fonts (Inter)

## Project Structure

```text
NorthPeak-Digital/
│
├── assets/
├── scripts/
├── styles/
├── index.html
└── README.md
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rushikesh-rane/northpeak-digital.git
```

Open the project folder and launch `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Form Validation

The contact form validates:

- Empty fields
- Email format
- Minimum message length (10 characters)

Valid submissions are stored in the browser's Local Storage.
